Code map: the central files

Code mapabout 5 min read

Code version: DeepSeek Harness @ ce7073d · 2026-10-30

Purpose#

The folder tree shows every folder of the repository. The tree also holds tests, docs, snapshots, and vendored code. This page lists the main source files that the concept pages and the tour of this site cite. Many of these files hold a plugin. Each row names the file, its line count, its main service or class, and the page that explains it.

The list is not complete. It is the set of files that the writers of this site opened and cited for each capability family. The final section below says how the list was made. See the repository's own docs/module-graph.md for the full, generated package dependency graph.

How this list was made#

A concept page, a learn page, or the tour of this site cites each file above. Most of these files also appear in an <x-code> excerpt. The line counts come from wc -l at the pinned commit.

This page leaves out the parts of the repository this site treats as out of scope. That includes vendor/ (Cordis and its foundation libraries), native/ (the Landlock/flock launcher), packages/experimental/*, and the Swift/C++ experimental macOS helper. The Python SDK (python/) drives DeepSeek Harness as a subprocess. It uses newline-delimited JSON-RPC on stdio with the bundled dsh executable (python/README.md:5, python/README.md:12).
