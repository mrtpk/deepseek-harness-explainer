DeepSeek Harness Explained

Code version: DeepSeek Harness @ ce7073d · 2026-10-30

DeepSeek Harness (dsh) is an open-source agent harness developed by DeepSeek AI (README.md:5). It is built on Cordis, an "everything-is-a-plugin" framework: every part of the product, including the model adapter, the tool registry, and the agent loop itself, is a plugin, replaceable from configuration (docs/architecture.md:9). This site explains the code at commit ce7073d. You need to know TypeScript and Node.js. You do not need to know Cordis or the agent-harness domain first: Everything is a plugin: Cordis starts there.

What it doesRuns an AI agent: a session, a turn/step loop against a model, a tool pipeline, and optional subagents, jobs and workflows (README.md:5, docs/architecture.md:81, docs/architecture.md:99, docs/architecture.md:138, docs/architecture.md:154, docs/subsystems/workflow.md:5).
Runs onNode.js 24.9 or later, TypeScript, pnpm workspaces (AGENTS.md:84).
Code sizeMostly TypeScript/TSX, split across pnpm workspace packages under packages/ and apps/. See Code map: the folder tree for exact counts.
Run itnpx @deepseek-ai/dsh web starts the Web UI at http://127.0.0.1:3080 (README.md:24, README.md:27).

The system map#

One run starts at a surface, boots a profile, then reaches the core runtime. The core runtime can delegate work. The list under the map links each part to its page.

  • Surfaces. The CLI boots a named profile (apps/cli/src/args.ts:168). With the headless profile, the CLI answers one task and exits (docs/architecture.md:23); dsh web serves the Web UI at http://127.0.0.1:3080 (README.md:27); Desktop is an Electron window that loads packaged Web assets (docs/architecture.md:53).
  • Profile and bundle boot. A profile stacks one or more bundles into a plugin tree (docs/architecture.md:17, docs/architecture.md:19). Everything is a plugin: Cordis explains the plugin mechanism itself.
  • Core runtime. The agent loop and session log, tools and MCP servers, and the LLM adapter do the work of each turn. In each step, the loop calls the model, then runs the tool calls in the response (packages/core/agent-loop/src/agent.ts:586-593).
  • Delegation. An agent can hand work to subagents (docs/architecture.md:138), background jobs (docs/architecture.md:154), or a workflow script (docs/subsystems/workflow.md:5).

Simplified

The map leaves out the sandbox and approval layer, MCP servers, skills, and the SDKs and ACP server that let other programs drive a session. The concept pages under "Execution and safety" and "Protocols and clients" cover these.
