Glossary

Referenceabout 8 min read

Code version: DeepSeek Harness @ ce7073d · 2026-10-30

This page lists every term that has a tooltip on this site. Each entry gives a short definition. Many entries link to a page with the full explanation.

A B C E G J M P R S T W

A#

ACP also: Agent Client Protocol

Agent Client Protocol. The automation-only JSON-RPC-over-stdio protocol the dsh-acp server implements.

packages/acp/acp/README.md:2

Read more: ACP, SDKs and clients

Agent

The live object that drives one session: it owns the turn/step loop and the inbox of pending input.

AgentRegistry publishes and tracks live Agents by session id (packages/core/agent/src/index.ts:484-492); ReactLoopAgent is the default implementation of the Agent interface (packages/core/agent-loop/src/agent.ts:112).

Read more: The agent loop and the session log

agent loop

The turn/step cycle that claims input, calls the model, runs the tools it asks for, and repeats.

ReactLoopAgent.turn() runs the steps of one turn (packages/core/agent-loop/src/agent.ts:327); each step calls the model, then runs its tool calls (packages/core/agent-loop/src/agent.ts:586-593).

Read more: The agent loop and the session log

approval policy also: approval

The human-in-the-loop decision for one action: may this specific action proceed?

docs/subsystems/approval.md:5

Read more: Approval and human interaction

B#

bundle

A distribution format for Cordis config rows and the code they mount, so whatever it inserts stays patchable by the layers above it.

docs/architecture.md:19

Read more: Profiles and bundles: how a running dsh tree is assembled

C#

capability seam also: seam

A swappable capability with three roles: a Service Definition, one or more Service Providers, and one or more Consumers.

docs/architecture.md:136. The seam is the complete capability; name a single role by its own name instead (docs/glossary.md:9).

Read more: Sandbox and execution

context also: ctx

A repository of services. A plugin reads another plugin's service through the context instead of importing it directly.

docs/cordis-primer.md:10

Read more: Everything is a plugin: Cordis

Cordis also: cordis framework

The vendored plugin framework under dsh. Plugins contribute services, typed events and reversible effects to a shared context.

dsh has no privileged core: every part of the product, including the model adapter, the tool registry and the agent loop, is a plugin, so each piece is replaceable from configuration (docs/architecture.md:9, docs/architecture.md:11).

Read more: Everything is a plugin: Cordis

E#

effect also: reversible effect, ctx.effect

A reversible registration a plugin makes on a context, made with ctx.effect() or ctx.on(). It unwinds on its own when the plugin unloads or reloads.

docs/cordis-primer.md:13. A core example: AgentRegistry.setFactory() registers inside ctx.effect() and returns the disposer that clears the slot (packages/core/agent/src/index.ts:384-392).

Read more: Everything is a plugin: Cordis

exchange

Consecutive turns from a turn whose first step admits human input until the next such turn.

Turns woken by notices, such as a settled subagent or a goal round, stay in the preceding exchange (docs/glossary.md:40).

Read more: Turn, step, round: the session vocabulary

G#

goal

One durable completion objective attached to a session, with an active/paused/blocked/complete phase and a goal-round cap.

docs/glossary.md:25

Read more: Jobs, workflows, goals and plan mode

J#

job also: background job

A long-running background unit tracked by ctx.jobs, with a status of running, stopping, completed, killed or failed.

docs/subsystems/jobs.md:21

Read more: Jobs, workflows, goals and plan mode

M#

MCP also: Model Context Protocol

Model Context Protocol. It connects the model to tools and resources supplied by external servers.

docs/subsystems/mcp.md:7

Read more: Tools and MCP servers

P#

plan mode

Logged per-agent collaboration state that adds a guidance section to each model request while active. It is soft guidance only.

Sandbox mode and approval policy enforce restrictions independently of plan mode (docs/subsystems/plan.md:5).

Read more: Jobs, workflows, goals and plan mode

plugin

An object that implements Service: a function with optional inject and apply(ctx) fields, or a Service subclass Cordis mounts into a context.

docs/cordis-primer.md:9

Read more: Everything is a plugin: Cordis

profile

A named plugin-tree composition stored in the Harness home. It lists the bundles it stacks and the user's own patch file.

Shipped profiles are web, headless, sdk, sdk-minimal and acp, selected with dsh --profile <name> (docs/architecture.md:17, docs/architecture.md:43).

Read more: Profiles and bundles: how a running dsh tree is assembled

provider adapter also: LLM adapter, adapter

An LlmAdapter object that streams model calls for one or more provider names. A plugin registers it with ctx.llm.registerAdapter().

Only stream() is abstract. The other LlmAdapter methods have a default (packages/llm/llm/src/index.ts:208, packages/llm/llm/src/index.ts:297-302).

Read more: The LLM seam and the system prompt

R#

round

An outer policy iteration containing a turn, such as a goal round. Round counters belong to that policy, not to every turn.

docs/glossary.md:39

Read more: Turn, step, round: the session vocabulary

S#

sandbox

The process-sandbox seam. It wraps a subprocess in a file-effect policy: read-only, workspace-write, or danger-full-access.

docs/subsystems/sandbox.md:5, docs/subsystems/sandbox.md:11

Read more: Sandbox and execution

sandbox escalation

A one-shot retry of a denied call at a strictly wider sandbox mode. It runs only after an approval answerer allows it.

A request for the current mode needs no approval. A strictly wider target goes through ctx.approval before the call runs (packages/sandbox/sandbox/src/escalation.ts:172-206).

Read more: Sandbox and execution

SDK wire protocol also: SDK protocol

The own newline-delimited JSON-RPC protocol of dsh, with one message per line. dsh-sdk-jsonrpc-server serves it over stdio. The TypeScript and Python SDKs speak it.

The protocol package (packages/sdk/protocol/src/index.ts:1-9). The framing rules are in packages/sdk/protocol/README.md:34.

Read more: ACP, SDKs and clients

service also: ctx key

What a plugin claims from a context: a stable ctx.<key> such as ctx.tools or ctx.llm, found by key instead of by import.

docs/cordis-primer.md:10

Read more: Everything is a plugin: Cordis

session

The durable conversation object: one Session holds one append-only event log and is the identity an agent runs on.

Session is an event-sourced, append-only log of SessionEvents (packages/core/session/src/index.ts:517-525). A live agent's id must equal its session id (packages/core/agent/src/index.ts:486-488).

Read more: The agent loop and the session log

session log also: event log, SessionEvent log

The append-only log of SessionEvent records. It is the source of the context the model sees.

deriveMessages() projects model history from this log (docs/architecture.md:59, docs/architecture.md:124).

Read more: The agent loop and the session log

skill

An optional, loadable instruction set, discovered through a provider registry under ctx.skills. Not a session event.

docs/subsystems/skills.md:5

Read more: Skills

step

One model request plus the tool executions caused by its response. A turn contains zero or more steps.

docs/glossary.md:38, docs/architecture.md:81

Read more: Turn, step, round: the session vocabulary

subagent also: child agent

A child agent a parent delegates work to through a named provider. A local child keeps a durable session; others execute once.

packages/subagent/subagent/README.md:12

Read more: Subagents and delegation

subagent provider also: provider

A named backend registered on ctx.subagents. A caller picks one by name. Providers differ in whether the child keeps a session.

Method presence selects the family. prepareContinuable() gives a local, durable child. A provider with only start() runs once (packages/subagent/subagent/src/types.ts:340-355).

Read more: Subagents and delegation

system prompt

The instruction text for one step. Assembly joins the visible prompt sections in ascending order.

The loop renders the assembly, then commits it to the session as a system/message event instead of a hidden request field (packages/core/agent-loop/src/agent.ts:442, docs/architecture.md:112).

Read more: The LLM seam and the system prompt

T#

tool call also: tool execution

One request from the model to run a tool, carried through the tools/pre-execute, tools/execute and tools/post-execute pipeline.

docs/architecture.md:99

Read more: Tools and MCP servers

tool restriction

An allow or deny name list (or both) on the global tools that one scoped agent can see. ctx.tools.restrict() applies it.

The type is ToolRestriction (packages/core/tools/src/contracts.ts:372-381). Several restrictions intersect. The scoped registrations of an agent stay visible (packages/core/tools/src/index.ts:158-189).

Read more: Subagents and delegation

turn

One drain of admitted input in a session. It opens before its first input is claimed and closes once nothing is owed.

A turn contains zero or more steps (docs/glossary.md:37, docs/architecture.md:81).

Read more: Turn, step, round: the session vocabulary

typed event also: event, cordis event

A named extension point a service declares, dispatched as emit, waterfall, parallel, serial or bail, depending on how its listeners must run.

docs/cordis-primer.md:12, dispatch-mode table at docs/cordis-primer.md:19-25.

Read more: Everything is a plugin: Cordis

W#

workflow

An optional capability that lets an agent run a model-written script that starts subagents. It is not part of the agent loop.

docs/subsystems/workflow.md:5

Read more: Jobs, workflows, goals and plan mode
