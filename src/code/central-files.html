Purpose

{{link code/index | The folder tree}} shows every folder of the repository. Most of that code is generated output, tests, docs, or a vendored library. This page lists the files that this site's {{term plugin | plugins}} and concept pages actually read and quote. Each row names the file, its line count, its main {{term service}} or class, and the page that explains it.

The list is not exhaustive. It is the set of files the writers of this site opened and cited while explaining each capability family. The final section below says how the list was made. See the repository's own {{cite docs/module-graph.md}} for the full, generated package dependency graph.

How this list was made

Every file above is one this site's writers opened, read, and quoted with an <x-code> excerpt on a concept page or the tour. Line counts come from wc -l against the pinned commit, counted again while writing this page. This page leaves out the parts of the repository this site treats as out of scope. That includes vendor/ (Cordis and its foundation libraries), native/ (the Landlock/flock launcher), packages/experimental/*, and the Swift/C++ experimental macOS helper. The Python SDK (python/) only launches the compiled dsh binary over JSON-RPC-on-stdio, and has no in-process harness logic ({{cite python/README.md:5-9}}).
