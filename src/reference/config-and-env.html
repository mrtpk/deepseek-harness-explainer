Purpose

This page is a short lookup, not a full catalog. It lists the environment variables, config layers, and command-line flags a reader meets first. For the complete, generated tables, see the repository's own {{cite docs/config-catalog.md}} and {{cite docs/tool-catalog.md}}.

Main environment variables

VariableDefault when unsetWhat it controls
DSH_HOME ~/.dsh ({{cite packages/util/home-paths/src/index.ts:70-72}}) The home directory for {{link learn/profiles-and-bundles | profiles, profile patch files, and user data}}. resolveDshHome() reads it ({{cite packages/util/home-paths/src/index.ts:135-137}}). An explicit configured path has priority. An empty value is the same as unset ({{cite packages/util/home-paths/src/index.ts:107-108}}).
DSH_AGENTS_HOME ~/.agents ({{cite packages/util/home-paths/src/index.ts:78-80}}) The shared agent configuration root ({{cite packages/util/home-paths/src/index.ts:139-153}}). When its config has no agentsHome, the filesystem {{term skill}} provider uses this root. It scans <root>/skills as one user skill root ({{cite packages/skill/skill-filesystem/src/index.ts:167}}, {{cite packages/skill/skill-filesystem/src/index.ts:264}}).
DEEPSEEK_API_KEY (none; a model request fails with MISSING_CREDENTIAL) ({{cite packages/llm/llm-deepseek-api-key/src/index.ts:46-50}}) The default credential name for the API key of the DeepSeek LLM adapter ({{cite packages/llm/llm-deepseek-api-key/src/config.ts:25}}). The apiKeyEnv field of the {{term plugin}} config can name a different credential. When a credentials service is mounted, the adapter asks it for the key. Without that service, the adapter reads the launch environment ({{cite packages/llm/llm-deepseek-api-key/src/index.ts:38-45}}).
DEEPSEEK_BASE_URL https://api.deepseek.com/anthropic ({{cite packages/llm/llm-deepseek/src/config.ts:116}}) Overrides the DeepSeek Messages endpoint. It applies only when the plugin config does not set baseURL ({{cite packages/llm/llm-deepseek/src/config.ts:311}}). The adapter reads it from the launch environment snapshot, not from process.env. A code comment says that only trusted layers can set it ({{cite packages/llm/llm-deepseek/src/config.ts:118-119}}).
HTTP_PROXY / HTTPS_PROXY / NO_PROXY (and the lower-case and ALL_PROXY forms) unset (direct connections) The launcher makes one proxy policy from these variables and installs it before the first plugin mounts ({{cite packages/util/http-proxy/src/policy.ts:39-54}}, {{cite apps/cli/src/profile-boot.ts:272-279}}). Node fetch does not read the proxy environment itself. Loopback addresses never go through the proxy ({{cite packages/util/http-proxy/src/policy.ts:25-33}}).

Config-file layering

A running dsh tree is a {{term profile}} that stacks named {{term bundle | bundles}}. Patch files then change the result: the bundle patches, the cordis.patch.yml of the profile, the home-level $DSH_HOME/cordis.patch.yml, and any --patch overlays ({{cite apps/cli/src/profile-boot.ts:211-217}}). {{link learn/profiles-and-bundles}} explains the full, fixed layer order, with a diagram and a worked example. This page does not repeat it.

Main CLI flags

These flags belong to the dsh launcher. {{cite apps/cli/src/args.ts}} parses them. The launcher stops at the first token that it does not recognize. It gives all tokens after that, without change, to the app of the booted profile ({{cite apps/cli/src/args.ts:4-9}}).

FlagMeaning
--profile <name>The profile under $DSH_HOME/profiles to boot ({{cite apps/cli/src/args.ts:168}}). dsh <name> is a shorthand for dsh --profile <name> when the first argument is not a flag and not plugin ({{cite apps/cli/src/args.ts:206-208}}).
--from-default-profile <name>Replaces a custom profile with a fresh copy of a shipped profile template before boot ({{cite apps/cli/src/args.ts:169}}).
--patch <path>Adds one extra patch-overlay file, applied after the profile's own layer. Repeatable; each use adds one more file, in argv order ({{cite apps/cli/src/args.ts:170}}).
--dump-config / --dump-default-config / --dump-config-schemaPrint the composed profile tree, the tree without the user layer and --patch overlays, or the JSON Schema for profile entries and patches. Then exit. A dump does not boot the tree, and it accepts no app arguments ({{cite apps/cli/src/args.ts:171-173}}, {{cite apps/cli/src/args.ts:122-127}}).
plugin --profile <name> <pnpm-args...>Forwards pnpm arguments to pnpm in the directory of one profile, to add, remove, or query a plugin dependency ({{cite apps/cli/src/args.ts:187-202}}).
